# Верификация и оценка надёжности автосервисов

Материалы ВКР и проектного семинара ИТМО.

**Автор:** Панин Дмитрий Владимирович, группа K3420.

**Тема:** «Аналитика и разработка автоматической верификации автосервисов и оценки их надежности в системе-агрегаторе для автосервисов, механиков и автовладельцев».

Работа связана с [Почини.Онлайн](https://pochini.online/). Я исследую, как проверять сведения об автосервисе и полномочия владельца профиля, а затем оценивать историю обслуживания так, чтобы пользователь понимал основания и ограничения результата.
