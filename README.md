# Верификация и оценка надёжности автосервисов

Материалы ВКР и проектного семинара ИТМО.

**Автор:** Панин Дмитрий Владимирович, группа K3420.

**Тема:** «Аналитика и разработка автоматической верификации автосервисов и оценки их надежности в системе-агрегаторе для автосервисов, механиков и автовладельцев».

Работа связана с [Почини.Онлайн](https://pochini.online/). Верификация рассматривается как подтверждение юридического лица или ИП, связанного с автосервисом. Надёжность оценивается для клиента по возрасту бизнеса, судебной истории, жалобам и другим проверяемым факторам. Результат должен понятно объяснять основания оценки и недостаток сведений.
